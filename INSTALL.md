# Установка бота на Windows

Нужно сделать один раз. Дальше бот запускается двойным кликом по `start.bat`.

## 1. Установите Python

1. Откройте https://www.python.org/downloads/ и нажмите жёлтую кнопку **Download Python**.
2. Запустите скачанный файл.
3. **Важно:** внизу первого окна поставьте галочку **Add python.exe to PATH**, потом нажмите **Install Now**.
4. Дождитесь надписи *Setup was successful* и закройте окно.

## 2. Папка с ботом

Папка `kdp-puzzle-bot` уже лежит в `C:\Aleks\ClaudeCode`. Если её нет, скачайте код с GitHub:
страница репозитория → зелёная кнопка **Code** → **Download ZIP**, и распакуйте архив.

## 3. Первый запуск

1. Дважды щёлкните `start.bat`. При первом запуске он сам установит всё нужное (1–2 минуты).
2. Откроется Блокнот с файлом `.env`. После `BOT_TOKEN=` вставьте токен бота @kid_01_bot от @BotFather
   (вместо слов `вставьте_сюда_токен`). Сохраните (Ctrl+S) и закройте Блокнот.
3. Снова запустите `start.bat`. В чёрном окне появится «Бот запущен».
4. Откройте бота в Telegram и напишите `/start`. Бот ответит вашим Telegram ID.
5. Откройте `.env` в Блокноте (правый клик → Открыть с помощью → Блокнот), впишите ID после `ADMIN_IDS=`,
   сохраните. Закройте чёрное окно и снова запустите `start.bat`.

Готово: пишите боту `/new`.

## Как пользоваться

- `/new` — бот кнопками спросит тему, виды головоломок, количество и сложность, потом соберёт книгу
  (примерно 20–40 секунд на 30–50 страниц).
- Приходят картинки-превью (первой идёт обложка) и три файла: `interior.pdf` (страницы книги), `cover.pdf` (обложка) и `listing.txt` (тексты для страницы книги на KDP). Копия сохраняется в папку `books`.
- «🔄 Другой вариант» — те же настройки, новые головоломки.
- Бот работает, пока открыто чёрное окно и компьютер не спит.

## Если что-то не так

- **«Python не найден»** — повторите шаг 1, не забудьте галочку *Add python.exe to PATH*.
- **Бот не отвечает** — проверьте, что чёрное окно открыто и в нём нет ошибки.
- **Любая другая ошибка** — пришлите Claude файл `logs\bot.log` из папки бота или скриншот окна.
- Файл `.env` содержит секретный токен: никому его не пересылайте.
